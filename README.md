# Footprint_China · 中国城市足迹地图

一个基于 Python 开发的中国城市足迹记录工具。

通过交互式中国地图，记录自己去过、生活过、学习过的城市，以及在这些城市留下的回忆。

## ✨ 主要功能

- **中国城市地图**：展示中国地级行政区地图，支持缩放和拖动。
- **城市足迹标记**：添加城市足迹，地图自动以淡粉色标记。
- **城市搜索**：通过城市名称快速搜索和添加足迹。
- **城市管理**：查看已添加的城市，支持删除误添加的足迹。
- **自定义城市标签**：为城市设置家乡、上学、旅游等标签，也可以自定义。
- **旅行日记**：为每座城市创建多条历史记录。
- **到达与离开时间**：分别记录到达和离开城市的时间。
- **记录管理**：支持查看、修改和删除历史记录。
- **足迹统计**：统计已记录的城市数量和省级行政区数量。

## 🛠️ 技术栈

- Python
- PySide6
- Qt WebEngine
- ECharts
- Shapely
- GeoJSON

## 📦 环境依赖

建议使用 Python 3.11 或更高版本。

需要安装以下依赖：

```bash
pip install PySide6 PySide6-WebEngine shapely
```

## 🚀 运行方法

1. 下载本项目。
2. 确保 `data` 文件夹中包含以下文件：

```text
data/
├── china_city.geojson
└── echarts.min.js
```

3. 安装上述 Python 依赖。
4. 在项目根目录运行：

```bash
python main.py
```

## 💾 数据存储

程序使用本地 JSON 文件保存城市足迹和历史记录。

数据文件：`data/visited.json`

所有记录保存在本地，无需注册账号，也不依赖在线服务器。

建议定期备份数据文件。
